📱 Als App auf dem Telefon speichern

iPhone Safari
  1. Öffne diese Seite in Safari (nicht Chrome)
  2. Tippe unten auf das Teilen-Symbol ⬆
  3. Scrolle und wähle „Zum Home-Bildschirm"
  4. Name bestätigen → Hinzufügen
Android Chrome
  1. Öffne diese Seite in Chrome
  2. Tippe oben rechts auf die drei Punkte ⋮
  3. Wähle „Zum Startbildschirm hinzufügen"
  4. Name bestätigen → Hinzufügen
Das HfMT-Logo erscheint als App-Icon. Die App öffnet sich ohne Browser-Leiste — wie eine echte App.
